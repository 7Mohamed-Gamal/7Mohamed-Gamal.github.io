نظام الدولية المؤسسي ومساعد الذكاء الاصطناعي (DJ_ELDawliya_sys)

منصة سحابية متكاملة لإدارة العمليات التشغيلية، المخازن، المشتريات، الاجتماعات، والمهام بـ Django، مدعومة بمساعد Google Gemini AI لتحليل البيانات واستخراج الرؤى.

💼 القيمة التشغيلية ونظرة عامة

منصة رقمية مركزية صُممت لإدارة شرايين العمل اليومي في الشركات التجارية والصناعية. تجمع المنصة بين إدارة الموارد البشرية، متابعة حركة الأصناف والمستودعات، أوامر الشراء، متابعة مهام فرق العمل بنظام المراحل، وتوثيق محاضر الاجتماعات وقراراتها، مع دمج مباشر لنماذج الذكاء الاصطناعي Gemini AI للإجابة على تساؤلات الإدارة وتحليل البيانات المعقدة.

❌ التحديات التقليدية التي تعاني منها الشركات

تشتت العمليات الإدارية بين ورقيات وبرامج منفصلة، ضياع قرارات الاجتماعات وعدم متابعة تنفيذها، غياب الرؤية اللحظية لمستويات المخزون مما يؤدي لنفاد البضائع أو تراكمها، وصعوبة استخلاص تحليلات سريعة من البيانات الضخمة.

✅ الحل الجذري الذي يقدمه النظام لعملك

نظام ERP موحد يربط المهام بالمخزون بالمشتريات، ويوثق محاضر الاجتماعات ويحول قراراتها إلى تكليفات تلقائية، ويوفر واجهات برمجية REST APIs مع مستشار ذكاء اصطناعي يقدم تقارير وتحليلات فورية.

⚙️ الوحدات والميزات التشغيلية الرئيسية

🤖 مساعد Google Gemini AI المدمج

تحليل أداء الأقسام، تلخيص محاضر الاجتماعات الطويلة، واستجواب قاعدة البيانات باللغة الطبيعية لاستخراج مؤشرات الأعمال.

📦 إدارة المخازن والمشتريات الذكية

مراقبة كميات الأصناف، تنبيهات الحد الأدنى للأرصدة، إنشاء طلبات الشراء تلقائياً وتتبع دورة اعتمادها حتى التوريد.

📝 نظام الاجتماعات ومحاضر القرارات

جدولة الاجتماعات، إرسال الدعوات ومتابعة الحضور، توثيق المحاضر رسمياً، وتعيين قرارات الاجتماع كمهام فورية للمسؤولين.

🎯 تتبع مهام الموظفين (Task Pipeline)

إنشاء المهام بخطوات تفصيلية، تتبع نسب الإنجاز، تحديد الأولويات، وعرض الأداء على تقويم وجداول زمنية تفاعلية.

🌐 واجهات REST API موثقة بـ Swagger

إمكانية ربط النظام بأي تطبيق جوال أو منصة خارجية عبر واجهات APIs سريعة ومحمية بـ JWT و API Keys.

📈 العائد المالي والتشغيلي (ROI) على شركتك

  • رقمنة 100% لقرارات ومحاضر الإدارة: عدم ضياع أي تكليف صادر عن الاجتماعات وتحويل القرارات الإدارية إلى واقع عملي ومحاسبي.
  • خفض تكاليف المخزون والهدر بنسبة 25%: تنبيهات مسبقة تمنع الركود أو النقص المفاجئ في المواد الخام والمنتجات التامة.
  • تسريع اتخاذ القرار عبر الذكاء الاصطناعي: الحصول على إجابات تحليلية دقيقة في ثوانٍ عبر محرك Gemini AI دون الحاجة لطلب تقارير يدوية مطولة.
